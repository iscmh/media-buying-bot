Cloning a Voice with Elevenlabs
VERY IMPORTANT
It's always better to copy a voice than to use a default one.
ElevenLabs has two different options that I like:

1. Instant voice clone
2. Voice Design
   INSANT VOICE CLONE
   I like to use instant voice clone. When I copy voices, they sound better than the ones i generate. Here's how it works:

- Download a video from yt/tt/reels
- Make it an mp3
- Upload it to 11labs instant voice clone feature
- That's it

You can even use professional voice clone if you want to go deeper but not that necessary.
VOICE DESIGN
This one is good also, you can design a voice and change the accent etc. Use this prompt to design a voice: [ELEVENLABS VOICE DESIGN](https://docs.google.com/document/d/1rgTmBOVa5o2Kw8nNeHFkSclm0xKBy_BrzDmsSZBNOUw/edit?usp=sharing)
Here's how it works:

- Upload image/video to gemini
- Use the prompt on the docs above
- Upload it to 11labs instant voice clone feature
- That's it
