Exact scene structure and sequence

Timing for each segment (timestamps)

Dialogue or voiceover script (word-for-word if possible)

B-roll suggestions for each part if needed

Camera angles, transitions, and visual style

Make sure the prompts are detailed, accurate, and aligned with the timing and visuals of the original video.
