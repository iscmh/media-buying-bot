### `runOneVariantHedra` flow (per variant)

Wrap each API call in an Inngest `step.run(...)` for retry
boundaries. All existing worker patterns from Polish-19/20 carry
over: BYOK key load via `loadDecryptedKeys(userId, ['hedra'])` (add
`'hedra'` to `HotProviderName`), `resolveAutoVideoDuration` fallback
chain for cost estimation only (Hedra bills by actual audio
duration).

1. **runClaudeAdSpec** — rewritten prompt (see below). Returns
   short-scene text_prompt + verbatim script for TTS.
2. **Nano Banana Pro reference image gen** — existing
   `callGeminiImage` + Polish-19.0.7 structured character prompt
   pattern. Uploads image bytes to Supabase for the operator
   run-detail page; hands raw bytes to Hedra.
3. **Refuse if `isHedraVoiceRosterUncurated()`** — surface clear
   "curate Hedra voices via scripts/hedra-list-voices.mjs" error.
4. **createHedraAsset({name, type: 'image'})** → asset id.
5. **uploadHedraAsset({assetId, bytes, contentType: 'image/png'})**
   — multipart. Bytes come from step 2's raw image.
6. **pickHedraVoicesForBatch(variantCount, offset)[variantIndex]**
   → `voice_id`. Offset by `job.id.hashCode() % roster.length` (or
   equivalent stable derivation) so concurrent batches don't always
   land the same voice on variant 0.
7. **submitHedraGeneration({aiModelId: config.modelParam,
   startKeyframeId: imageAssetId, tts: {voiceId, text: script},
   textPrompt: sceneDescription, resolution: '720p', aspectRatio:
   '9:16'})** → generation id.
8. **pollHedraGeneration** until status ∈ {`complete`, `error`}.
   Poll interval: 5s. Warmup: 8s (Character 3 takes 30-90s
   typically).
9. **Download mp4** from `downloadUrl` (presigned S3-style, use
   raw fetch not chokepoint) → upload to Supabase
   `generated_creatives` bucket → write `generated_creatives` row.

### Claude system prompt rewrite

`packages/ai-providers/src/claude-client.ts` → `runClaudeAdSpec`.
Current prompt (Polish-20.0.3) instructs yapper-style flowing prose

- word-count calibration + `sound_texture` field. For Character 3:

* **Scene description**: 50-80 words per variant. Setting, character
  context (age/gender/persona hint), tone, framing, lighting. NO
  motion beats, NO camera choreography — Character 3 handles
  animation from audio.
* **Verbatim source script preservation**: KEEP the Polish-19.4.2
  rule. Hook variants must include verbatim source ad phrases. This
  is the core ad-copy skill Claude adds.
* **DROP**: `sound_texture` field (Hedra handles audio natively via
  TTS), per-segment word-count calibration (single-call model),
  speaker attribution boilerplate, yapper flowing-prose
  instructions.
* **Output schema**: `{scenes: [{scene_description, script}, ...]}`
  where scenes.length === variantCount. Removes the `segments[]`
  structure since each variant is a single Hedra call.
